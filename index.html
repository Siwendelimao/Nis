开发者

也可以命令行来

不想点按钮的话，一行命令就能把安装包拉到当前目录；想改代码就从源码跑。

一行拉取安装包（Windows PowerShell）

$u = 'https://github.com/Siwendelimao/Nis/releases/latest/download'
irm "$u/NIS_Setup_1.1.5_x64.exe" -OutFile NIS_Setup_1.1.5_x64.exe

从源码跑（需要 Node 20+ 与 pnpm）

git clone https://github.com/Siwendelimao/Nis.git
cd Nis && pnpm install && pnpm dev

源码方式跑起来后打开 http://127.0.0.1:5174；手机接入和桌面端一样，走局域网 IP 即可。

常见问题

你可能想问

一定要自己配 API Key 吗？

要。NIS 不自带模型额度，你用哪家模型就配哪家的 Key。也可以接本地 Ollama，那样完全离线、不花一分钱。

支持哪些系统？

目前只在 Windows 10 / 11 上验证过（桌面端基于 Tauri 2 + WebView2）。代码里只有少量 Windows 专属部分，欢迎 PR 补平台适配。

我的数据会被上传吗？

不会。会话、记忆、文件都在本机；只有你自己配置的模型 API 会被调用。

收费吗？

NIS 本身开源免费（MIT 协议）。模型费用由你用哪家供应商自己决定，跟 NIS 无关。

需要装 Python 吗？

不做语义记忆检索就不需要；想要完整的记忆 / 知识库功能，建议装 Python 3.10 以上。
